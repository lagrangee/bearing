# Unsupported Configuration

## Applicability

Use when Configure Inspect reports Invalid or Unsupported Preview state.

## Authority

Bearing may explain the incompatibility and, only when the Human chooses it, coordinate an explicit
reviewed platform removal. It does not migrate, repair, purge, or reinterpret unsupported bytes.

## Operation

1. Stop before the requested operation and report the typed unsupported facts, preserved data
   boundary, and why the current runtime cannot continue. Do not use direct repository reads to
   continue the rejected operation or produce a degraded result.
2. Stop with the unsupported repository preserved. If the Human explicitly chooses removal,
   prepare an external, exact, Agent-reviewed removal proposal and obtain separate authority before
   any removal.
3. Validate an accepted removal before reporting Fresh. Fresh Configuration is a distinct later
   operation; unsupported state never authorizes migration, silent repair, broad deletion, or
   automatic Fresh activation.

## Completion criterion

Unsupported state remains untouched unless one external, exact removal is separately accepted and
validated before a distinct Fresh workflow.
