# Next Work

## Applicability

Use only when the user explicitly asks what to do next or requests current work guidance.

## Authority

Next Work is transient Agent judgment. It reads current Orientation, planning, Attention, Audit,
and trustworthy native frontier facts. It does not prioritize canonically, select an executor, or
start work.

## Operation

1. Inspect current Project Context and deepen only the candidate planning/native references needed
   for a trustworthy frontier.
2. Rank only evidence-backed directions. Recommendation count, grouping, and ordering remain Agent
   judgment; omit filler alternatives, and state the reason and owner for each recommendation.
3. Return guidance in conversation only. A selected direction starts only through its real Work
   Management, Execution, or semantic owner.

## Completion criterion

The response is current, evidence-backed, proportionate, and transient; it persists no
recommendation or priority change and leaves every effect to its owner.
