# Next Work

## Applicability

Use only when the user explicitly asks what to do next or requests current work guidance.

## Authority

Next Work is transient Agent judgment. It reads current Orientation, planning, Attention, Audit,
and trustworthy native frontier facts. It does not prioritize canonically, select an executor, or
start work.

## Operation

1. Inspect current Project Context and deepen only the candidate planning/native references needed
   for a trustworthy frontier. Completion: current managed constraints and evidence limits are
   explicit.
2. Rank only evidence-backed directions. Recommendation count, grouping, and ordering remain Agent
   judgment; omit filler alternatives. Completion: each recommendation states reason and owner.
3. Return guidance in conversation only. Completion: no artifact, queue, or selection is persisted.

## After this operation

- **Consider:** A selected direction starts only through its real Work Management, execution, or
  semantic owner.
- **Do not infer:** Guidance reprioritizes work, accepts planning meaning, changes lifecycle, or proves
  that no unmanaged work exists.

## Completion criterion

The response is current, evidence-backed, proportionate, transient, and leaves every effect to its
owner.
