# Issue tracker: Local Markdown

Issues and PRDs live under `.scratch/`.

Provider contract: `matt-skills/v1`

## Conventions

- One feature per directory.
- The PRD is `.scratch/<feature>/PRD.md`.
- Tickets are `.scratch/<feature>/issues/<NN>-<slug>.md`.
- Claim sets `Status: claimed` before work.
- Resolution requires completed acceptance, an Answer, and implementation evidence.

## When a skill says "publish to the issue tracker"

Create the requested Markdown file under `.scratch/<feature>/`.

## When a skill says "fetch the relevant ticket"

Read the exact referenced ticket file.

## Wayfinding operations

Use one Map with child tickets. Do not select a ticket by approximate title when more than one
native ticket matches the request.
